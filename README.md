# 🛍️ E-Commerce Platform - Laravel

> A full-featured e-commerce platform built with Laravel 10, demonstrating MVC architecture, RESTful API design, and modern PHP development practices.

---

## 🎯 About The Project

This is a college project showcasing a complete e-commerce platform built using **Laravel framework** with **MVC architecture** and **CRUD operations**. The project demonstrates understanding of:

- ✅ Model-View-Controller (MVC) design pattern
- ✅ RESTful API development
- ✅ Database relationships and migrations
- ✅ Authentication & Authorization
- ✅ Modern PHP frameworks
- ✅ Clean code practices

### **Learning Journey**

This is the framework-based version of my e-commerce project. I also built a [vanilla PHP version](https://github.com/Saad05-dev/ecommerce-project-vanilla-php) to understand core concepts before using frameworks.

---

## 🛠️ Tech Stack

### Backend
- **Framework:** Laravel 10.x
- **Language:** PHP 8.1+
- **Database:** MySQL 8.0
- **Authentication:** Laravel Sanctum / Breeze
- **ORM:** Eloquent

### Frontend
- **Template Engine:** Blade
- **CSS Framework:** Tailwind CSS 3.x
- **JavaScript:** Alpine.js / Vanilla JS
- **Icons:** Boxicons

### Tools & Services
- **Server:** Apache (XAMPP)
- **Package Manager:** Composer
- **Version Control:** Git
- **API Testing:** Postman
- **Code Editor:** VS Code
